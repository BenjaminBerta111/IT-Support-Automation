# IT-Support-Automation

A collection of lightweight automation scripts and utilities designed to streamline system maintenance, manage inputs, and handle data extraction.

## RightClickDisable
A background script that blocks right-click mouse inputs when toggled via the `F8` key. Built as a hardware workaround for faulty mouse switches, it intercepts input signals at the system level and is configured to run silently in the background automatically upon system startup.

## WebScraper2
A simple Python and HTML utility designed to extract text, images, and hyperlinks from web pages. Optimized for static content structures like wikis, it parses page data directly without the overhead of launching separate browser instances.

## backup.bat
A batch automation script that secures source code assets. When executed, it scans its current directory and copies all `.py`, `.js`, and `.html` files into a dedicated backup folder for local version control.

## cleanoutpc.bat
A system maintenance script designed for quick PC optimization. It automatically flushes the system DNS cache and purges temporary file directories (`temp`) to reclaim disk space and resolve network hiccups.

## powerflipper.bat
A configuration script that instantly toggles the Windows power scheme between Balanced (Recommended) and High Performance modes, bypassing manual Control Panel navigation.

## QuickTab
A background productivity script that binds a global shortcut (`Ctrl + Space`) to instantly launch a new Firefox browser tab, bypassing manual desktop navigation.

## How to use

To use any of these, either right click the program or run it in command prompt, if they dont work, simply run the command prompt as administrator.
